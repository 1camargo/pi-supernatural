# 👻 Portal dos Caçadores

Bem-vindo ao **pi-supernatural** – uma aplicação web interativa para fãs da série *Supernatural*. Com uma interface inspirada na estética sombria da série, a plataforma permite que usuários explorem conteúdos sobre o universo de *Supernatural*, criem contas, relatem atividades paranormais fictícias e visualizem os relatos em uma dashboard dinâmica.

---

## 🔮 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio prático com o objetivo de aplicar conhecimentos em **desenvolvimento full stack**. A aplicação oferece:

- Sistema de login e cadastro de usuários
- Área para relatos de atividades paranormais
- Dashboard com gráficos gerados dinamicamente a partir dos dados armazenados no banco de dados
- Estilo visual baseado na série Supernatural, utilizando fontes como **Special Elite** e **Poppins**, e elementos visuais que remetem ao universo da série

---

## ✨ Tecnologias Utilizadas

- **Front-end:** HTML, CSS e JavaScript
- **Back-end:** Node.js, Express
- **Banco de Dados:** MySQL
- **Visualização de Dados:** API `web-data-viz`
- **Outras Ferramentas:** Trello, Git, GitHub

---

## 🧰 Instalação e Execução

Para rodar este projeto na sua máquina, siga os passos abaixo:

```bash
# Clone o repositório
git clone https://github.com/1camargo/pi-supernatural.git

cd pi-supernatural

# Instale as dependências
npm install

# Configure seu banco de dados
# Atualize as credenciais no arquivo de configuração (.env ou config.js)

# Inicie a aplicação
npm start
```
>⚠️ Certifique-se de ter o MySQL rodando e o banco de dados configurado conforme os modelos do projeto.

## 📝 Funcionalidades

- ✅ Cadastro e autenticação de usuários  
- ✅ Relato de eventos sobrenaturais (tipo, local, descrição, nível de urgência)  
- ✅ Armazenamento e visualização dos relatos em um painel com gráficos  
- ✅ Interface visual inspirada na série Supernatural   

---

## 📊 Dashboard

Os relatos feitos pelos usuários são apresentados em gráficos interativos, permitindo uma visualização clara e dinâmica dos dados armazenados. A integração com a API `web-data-viz` oferece uma experiência envolvente e informativa para os fãs da série.
